자동 기입기 개인정보 처리방침

최종 수정: 2026-09-27

자동 기입기(Autofill KR)는 웹 페이지의 입력 칸에, 사용자가 직접 넣어 둔 값을 채워 주는 크롬 확장입니다.

다루는 정보

  • 내 정보 — 사용자가 설정 화면(입력값 관리)에 직접 넣은 이름·아이디·닉네임·휴대폰 번호·생년월일·성별 숫자·통신사·이메일·우편번호·주소.
  • 사이트별 기억 — 사용자가 «채우기»·«기억하기»로 저장한 페이지의 주소(출처와 경로, 물음표 뒤 값은 빼고)와 저장·수정 시각, 칸의 생김새(칸 이름·이름표·순서 등), 그 칸에 넣을 값 또는 «내 정보의 어느 항목»인지. 누르기로 기억한 버튼의 글자.
  • 페이지 내용 읽기 — 칸의 뜻을 알아보려고 지금 보고 있는 페이지의 입력 칸과 이름표·주변 글자를 읽습니다. 읽은 글자는 위의 «칸의 생김새» 말고는 저장하지 않고, 어디로도 보내지 않습니다.
  • 설정 — 제안을 끈 화면의 주소, 시작하기 진행, 시험·디버그 모드 등.

어디에 두나

모든 정보는 사용자의 크롬 프로필 안 chrome.storage.local 에만 저장됩니다. 구글 계정 동기화(chrome.storage.sync)를 쓰지 않습니다. 확장을 지우면 함께 지워집니다.

내 정보와 칸마다 적어 둔 값은 AES-GCM(256비트)으로 암호화해 저장합니다. 암호를 푸는 열쇠는 이 확장만 여는 저장 공간에 꺼낼 수 없는 형태로 둡니다. 다만 열쇠도 같은 크롬 프로필 안에 있으므로, 이 컴퓨터 계정에 접근한 사람이나 악성 프로그램으로부터는 완전히 보호되지 않습니다. 공용 컴퓨터에서는 사용하지 마세요.

어디로 보내나

어디로도 보내지 않습니다. 자동 기입기는 서버가 없고, 네트워크 요청을 하지 않으며, 분석·광고·원격 코드를 쓰지 않습니다. 값은 사용자가 보고 있는 페이지의 입력 칸에만 들어갑니다.

하지 않는 것

  • 폼을 제출하거나, 동의·인증번호 요청 버튼을 누르지 않습니다(사용자가 직접 기억시킨 선택 버튼만 누릅니다). 엔터 키를 보내지 않습니다.
  • 비밀번호·인증번호·보안문자·주민등록번호 뒷자리·계좌·카드 번호 칸은 다루지 않습니다.
  • 정보를 판매하거나 제3자에게 제공하지 않습니다.

권한

  • storage: 위 정보를 이 컴퓨터에 두기 위해.
  • scripting, activeTab, 선택 권한 *://*/*: 사용자가 값을 기억한 사이트 또는 «모든 사이트에서 제안 받기»를 켠 경우, 칸을 알아보고 채우기 위해. 사이트 접근은 설치할 때 묻지 않고 필요할 때 묻습니다.
  • contextMenus: 우클릭 메뉴(이 칸 값 기억하기 등).

지우기

입력값 관리 화면에서 내 정보의 각 항목과 사이트별 기록을 지울 수 있습니다. 확장을 제거하면 모든 정보가 지워집니다.

Autofill KR — Privacy Policy

Last updated: 2026-09-27

Autofill KR is a Chrome extension that fills web form fields with values the user entered into the extension.

What it stores: the profile the user types in (name, user ID, nickname, mobile number, date of birth, gender digit, carrier, email, postal code, address), per-site records of which fields to fill (the page address without query string, save time, field descriptors and either a value or a reference to a profile item), buttons the user asked it to click, and settings (including addresses of pages where suggestions were turned off). To recognise fields it reads the input fields, labels and nearby text of the page being viewed; that text is not stored beyond the field descriptors and is never sent anywhere. Everything is kept in chrome.storage.local inside the user's browser profile. chrome.storage.sync is not used. Profile data and saved field values are encrypted at rest with AES-GCM (256-bit); the key is a non-extractable key kept in the extension's own storage. Because the key lives in the same browser profile, this does not protect against someone with access to the computer account or against malware.

What it sends: nothing. There is no server, no network request, no analytics, no ads and no remote code. Values only go into the input fields of the page the user is on.

What it never does: submit forms, press consent or verification-request buttons (only choice buttons the user explicitly asked it to remember), send the Enter key, or touch password, one-time-code, CAPTCHA, resident-registration-number, bank-account or card-number fields. Data is never sold or shared.

Permissions: storage to keep the data locally; scripting, activeTab and the optional *://*/* host permission to recognise and fill fields on sites the user saved values for, or on all sites if the user turns that on (asked when needed, not at install); contextMenus for the right-click menu.

Deleting data: remove items in the extension's options page, or uninstall the extension to delete everything.
